# StickyLock

Windows **스티커 메모**를 블러로 가려 두고, 비밀번호를 입력한 메모만 보이게 하는 작은 프로그램입니다.
옆자리에서 화면을 볼 때 메모 내용이 그대로 노출되는 걸 막아 줍니다.

- 메모마다 **따로** 열고 잠급니다.
- 블러 상태에서도 메모를 **끌어서 옮길 수** 있습니다.
- 설치 과정도, 인터넷 연결도 필요 없습니다. 비밀번호는 **내 컴퓨터에만** 저장됩니다.

## 필요한 것

- Windows 10 또는 11
- [Python 3.8 이상](https://www.python.org/downloads/) (설치할 때 "Add Python to PATH" 체크)
- 추가 설치 패키지 없음 (윈도우 기본 기능과 Python 기본 모듈만 사용)

## 시작하기

### 방법 A. exe 파일 (파이썬 설치 없이)

1. [Releases](https://github.com/kwonyouyoung926-sudo/sticky-notes-blur/releases)에서 `StickyLock.exe`를 받습니다.
2. 더블클릭합니다.
3. 처음 한 번만 비밀번호를 정합니다. (2자 이상, 숫자 2자리를 추천합니다)

서명되지 않은 프로그램이라 처음 실행할 때 윈도우가 `추가 정보` → `실행`을 요구할 수 있습니다.

### 방법 B. 소스 코드로 실행

1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP` → 압축 풀기)
2. `run.bat`을 더블클릭합니다.
3. 처음 한 번만 비밀번호를 정합니다.
4. 스티커 메모 창이 블러로 덮이면 준비 끝입니다.

`build-exe.bat`을 실행하면 직접 `dist\StickyLock.exe`를 만들 수도 있습니다.

PC를 켤 때 자동으로 실행하려면 툴바의 `⚙` → `윈도우 시작할 때 자동 실행`을 누르세요.
지금 실행 중인 방식(exe 또는 파이썬)이 그대로 등록되고, 같은 메뉴를 한 번 더 누르면 해제됩니다.
`install-startup.bat` / `uninstall-startup.bat`으로도 할 수 있습니다.

### "게시자를 확인하지 못했습니다" 창이 뜰 때

인터넷에서 받은 파일에 윈도우가 붙이는 안내입니다. 파일에 문제가 있다는 뜻은 아니며,
`실행`을 누르면 그대로 사용할 수 있습니다. 아예 안 뜨게 하려면 셋 중 하나를 쓰세요.

- **압축 풀기 전에**: 받은 ZIP 우클릭 → 속성 → 아래쪽 `차단 해제` 체크 → 확인
- **이미 풀었다면**: 폴더에서 PowerShell을 열고 `Get-ChildItem -Recurse . | Unblock-File`
- **ZIP 대신 git으로 받기**: `git clone https://github.com/kwonyouyoung926-sudo/sticky-notes-blur.git`

## 사용법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 메모 열기 | 블러 가운데 `_ _` 칸을 클릭하고 비밀번호 입력 (다 채우면 자동 확인) |
| 한 글자 지우기 / 전부 지우기 | `Backspace` / `Esc` |
| 그 메모만 다시 잠그기 | 메모 오른쪽 아래 유리 자물쇠 버튼 클릭 |
| 모든 메모 잠그기 | 툴바의 `모두 잠그기` |
| 잠긴 채로 메모 옮기기 | 블러 부분을 끌기 |
| 스티커 메모 켜기 | 툴바의 `메모 열기` |
| 툴바 옮기기 / 접기 / 제자리 | `⠿` 손잡이를 끌기 / `▾` / 제목 더블클릭 |
| 비밀번호 변경·자동 실행·종료 | 툴바의 `⚙`, 또는 자물쇠 버튼 우클릭 |

열어 둔 메모는 60초 동안 사용하지 않거나, 최소화하거나 닫으면 자동으로 다시 잠깁니다.
비밀번호를 5번 연속 틀리면 30초 동안 입력할 수 없습니다.

## 설정 바꾸기

`sticky_lock.pyw` 맨 위 "설정" 부분의 숫자만 바꾸면 됩니다.

| 항목 | 설명 | 기본값 |
| --- | --- | --- |
| `AUTO_LOCK_SECONDS` | 안 쓰면 자동으로 잠기는 시간(초). `0`이면 끔 | `60` |
| `MIN_PASSWORD_LEN` | 비밀번호 최소 길이 | `2` |
| `MAX_FAILS` / `FAIL_COOLDOWN` | 연속 실패 허용 횟수 / 대기 시간(초) | `5` / `30` |
| `BLUR_TINT` | 블러 색과 진하기 (`0xAABBGGRR`, 앞 2자리가 진하기) | `0x66F2F2F2` |
| `GLASS_TINT`, `GLASS_HOVER` | 자물쇠 버튼 색 | 회색 계열 |
| `FONT` | 글꼴 | `Malgun Gothic` |

## 어떻게 동작하나요

1. 0.12초마다 화면에서 스티커 메모 창을 찾습니다.
2. 메모와 똑같은 크기·위치·둥근 모서리로 창을 만들어 그 바로 위에 올립니다.
3. 그 창에 윈도우의 아크릴(흐림) 효과를 걸어 메모 내용을 가립니다.
4. 비밀번호가 맞으면 그 메모의 가림막만 치웁니다.

비밀번호는 PBKDF2-SHA256(20만 회)으로 해시해서 `%APPDATA%\StickyLock\config.json`에 저장합니다.
원래 글자는 어디에도 저장되지 않고, 프로그램은 네트워크를 전혀 사용하지 않습니다.

## 알아두세요

- 화면을 가려 주는 도구이지 **암호화가 아닙니다.** 스티커 메모의 원본 데이터와 클라우드 동기화 내용은 그대로입니다. 작업 관리자에서 이 프로그램을 끄면 메모가 다시 보입니다.
- 윈도우 11의 스토어 버전 스티커 메모에서 만들고 확인했습니다. 메모 창을 찾는 방식은 창 제목(`스티커 메모` / `Sticky Notes`)과 프로세스 이름을 함께 보기 때문에 다른 언어에서도 동작합니다.
- PC를 켤 때 스티커 메모가 StickyLock보다 먼저 뜨면 1~2초 정도 메모가 보일 수 있습니다. 스티커 메모 자체의 자동 실행을 끄고 툴바의 `메모 열기`로 켜면 이 틈이 없습니다.
- 메모리 약 35MB, CPU는 평상시 1코어의 0.5% 정도를 씁니다.
